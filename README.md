# Living Hub | AI

Landing page ufficiale di presentazione: **Piattaforma in fase di sviluppo**.

Pagina statica responsive, senza dipendenze, tracker o servizi esterni. Il logo originale è incluso in `logo-living.png`.

## GitHub Pages

In **Settings → Pages**, scegli **Deploy from a branch**, branch **main**, cartella **/ (root)** e premi **Save**.

L'indirizzo previsto è https://cristiancerritelli-jpg.github.io/living-hub-ai/ . Usa l'indirizzo confermato da GitHub Pages come URL della voce **Living Hub | AI** nella barra del sito.

Per l'anteprima locale apri `index.html`. Modifica i testi in `index.html` e l'aspetto in `style.css`.
