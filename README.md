# Living Hub | AI

Landing page ufficiale di presentazione: **Piattaforma in fase di sviluppo**.

Pagina statica responsive, senza dipendenze, tracker o servizi esterni. Il logo originale è incluso in `logo-living.png`.

## GitHub Pages

In **Settings → Pages**, scegli **Deploy from a branch**, branch **main**, cartella **/ (root)** e premi **Save**.

L'indirizzo previsto è https://cristiancerritelli-jpg.github.io/living-hub-ai/ . Usa l'indirizzo confermato da GitHub Pages come URL della voce **Living Hub | AI** nella barra del sito.

Per l'anteprima locale apri `index.html`. Modifica i testi in `index.html` e l'aspetto in `style.css`.

## Dashboard demo

La dashboard interattiva è disponibile in [`dashboard/index.html`](dashboard/index.html). Include una sezione Immobili con ricerca e filtri, dettaglio immobile e checklist documenti. Nella demo le richieste ai professionisti sono simulate; non vengono inviate notifiche reali.

Se GitHub Pages è attivo sul branch `main` e sulla cartella `/ (root)`, la pagina è raggiungibile a https://cristiancerritelli-jpg.github.io/living-hub-ai/dashboard/ . I dati sono dimostrativi; la dettatura dipende dal browser e dal permesso del microfono.
